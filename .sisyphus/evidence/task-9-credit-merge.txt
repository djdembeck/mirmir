### Changes in harmonizer/merge.ts

1. Added `TrackCredit` to type imports (line 23)

2. Added `mergeTrackCredits()` exported function (after `mergeLabels`):
   - Takes `target: TrackCredit[]` and `sources: Array<TrackCredit[] | undefined>`
   - Uses a Map keyed by normalized (name, role) pair for deduplication
   - When same person+role found across sources: merges sources, externalIds, creditedName, originalRole, mbid
   - When same person+different role: creates separate credits
   - Case-insensitive deduplication key

3. Added `makeCreditKey()` helper: normalizes name+role to lowercase for dedup

4. Added `mergeExternalIdArrays()` helper: deduplicates ExternalEntityId by (provider, type, id)

5. Added Phase 3 credit merge block (after recording merge, before return):
   - Iterates all media/tracklist
   - Collects credits from all available source releases for each track position
   - Calls `mergeTrackCredits()` on each track's credits
