Task 13: MB Injection UI — Credit Selection + Injection Flow
=============================================================
Date: 2026-05-15
Branch: feat/mirmir-revitalization

FILES CREATED
-------------
1. server/islands/CreditSelector.tsx
   - Manages credit selection state with checkboxes
   - Groups credits by role with "Select all / Deselect all" per role group
   - Disables credits without MBID (shows "No artist MBID")
   - Disables work-level credits (Composer, Lyricist) with tooltip "Work-level relationship — skip for v1"
   - Exports getCreditKey() and isCreditInjectable() helpers

2. server/islands/InjectionFlow.tsx
   - 5-step injection workflow: Review → Dry Run → Confirm → Progress → Results
   - Review step: shows selected credits grouped by track
   - Dry Run step: calls /api/inject with dryRun=true, displays wouldSubmit/wouldSkip counts and details
   - Confirm step: modal-style warning "You are about to edit MusicBrainz"
   - Progress step: spinner + progress bar showing "X of Y credits processed"
   - Results step: success/failure per credit with edit URLs
   - Defaults to test.musicbrainz.org

3. server/islands/CreditInjector.tsx
   - Wrapper component that toggles between "view" and "select" modes
   - Shows MB editing warning prominently when in select mode
   - Integrates CreditSelector + InjectionFlow
   - Passes selected credits to InjectionFlow

4. server/routes/api/inject.ts
   - POST /api/inject endpoint
   - Accepts { recordingMbid, credits, dryRun? }
   - Reads MIRMIR_MB_USERNAME, MIRMIR_MB_PASSWORD, MIRMIR_MB_BASE_URL from env
   - Returns 503 if credentials not configured
   - Uses MBInjector class for dryRun and actual injection
