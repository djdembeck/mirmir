## Key Implementation Details
- MBInjector class authenticates via session-based login (GET /login for CSRF, POST /login for session cookie)
- injectCredits() builds rels.{N}.* form fields and POSTs to /recording/{mbid}/edit
- dryRun() returns same structure without making any HTTP calls
- Work-level credits (Composer, Lyricist, Songwriter) are skipped with logged warning
- Credits without mbid are skipped
- Credits with unconfirmed mappings (empty UUIDs) are skipped
- Attributes with empty typeIds are silently omitted from form fields
- Rate limited to 1 req/sec (MB bot guidelines)
- Edit notes included in all submissions: "Imported with mirmir, using data from: [sources]"
- rels.{N}.backward = "1" (recording is entity1 in MB relationship model)
